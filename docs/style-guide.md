# RIBA UI Style Guide (SaaS)

## Typography
- Font: Inter (system fallback)
- Scale: 12 / 14 / 16 / 18 / 24 / 32 / 40
- Line height: 1.6 body, 1.2 headings
- Contrast: AA compliant for text on backgrounds

## Color
- Brand Green: #0B6E4F (hover #0a5c42)
- Neutral Text: #111827 / #4B5563
- Borders: #E5E7EB
- Placeholder: #9CA3AF

## Spacing Rhythm
- Sections: 40px
- Blocks: 24px
- Inputs: 16px
- Label to input: 12px

## Components
- Card: radius 12px, padding 32/28, shadow 0 8px 24px rgb(16 24 40 / 0.08)
- Input: 48px height, 1px #E5E7EB, focus ring 1.5px brand green
- Buttons:
  - Primary: solid brand green
  - Secondary: border‑only
  - Tertiary: dashed/text

## Accessibility
- Keyboard focus visible, proper labels, ARIA for controls
- Minimum tap targets: 44px on mobile

## Responsiveness
- Breakpoints: 640px / 1024px
- Stack hero on mobile; center actions
